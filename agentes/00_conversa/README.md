# `00_conversa`

A primeira conversa com um agente: um modelo, um nome, uma descrição e uma
instrução. Quatro campos — o núcleo do ADK.

## Por que esta pasta existe

Antes de ferramenta, rede ou orquestração, vale sentir o comportamento cru:
o agente obedece à instrução; quando a pergunta pede um fato do mundo, ele
responde com a mesma segurança de quem sabe. A única fonte dele é o próprio
modelo. As pastas seguintes nascem deste mesmo objeto.

## Rodar

```bash
just cli 00_conversa
# ou: just web  → escolha "00_conversa"
```
