# `07_ata`

O debate com cada fala copiada para `state["ata"]` via callback.

## Por que esta pasta existe

Depois do laço, a aba **State** mostra a ata completa — rodada e autor —
montada em Python. A instrução dos três é a mesma função, lendo a mesma
transcrição. Sete chamadas; mais tokens no prompt.

## Rodar

```bash
just cli 07_ata
# persistir sessão: just web-memoria
```
